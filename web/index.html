How the assistant looks at the Unreal level.

off — no rendering at all. The assistant is then told it cannot see Unreal and must say so instead of guessing. This wins over any request: off means off.
camera — renders from a camera inside the level, so it works no matter which window you are using. It carries no post-processing, so emissive materials do not glow in it. Good for checking placement, materials and breakage — not for judging how something looks.
viewport — the real editor view including bloom. ⚠️ Produces no file and no error unless the Unreal window is in the foreground.

        Rig to mesh binds a bare mesh to this folder's skeleton, in two steps with your own work in between. Prepare joins the selected mesh pieces and voxel-remeshes them into one closed piece — that is what makes automatic weights work at all on generated meshes. Then check the rig actually sits inside the mesh: fit bones in Edit mode (that is the rest pose — posing in Pose mode looks right and collapses on the first animation). Then select mesh + rig and Bind, which reports how many vertices really got weighted. ⚠️ Remesh is destructive (UVs and materials go, texture comes back via a bake) — turn it off for hard-surface meshes and anything already clean. Same skeleton, different tissue = the clips in this folder all still fit.
        
              
        Spawn the rig, keyframe your animation, then Save FBX to store the clip. Animate re-applies a saved clip onto the rig selected in the scene. Append hangs the selected clip onto the end of what is already playing; playlist → Sequence builds the whole chain at once, blended at the seams — each clip picks up where the previous one stood and faces the way it was heading, and the creature stays where you put it. The playlist is per folder and clears when you switch. Save Mesh stores every mesh bound to this skeleton as a spawnable variant (rig + full creature). Everything binds to this folder's skeleton — no cross-rig retarget needed.
